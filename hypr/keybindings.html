Hyprland Keybindings

Media Controls (hardware keys)

XF86AudioMute
Volume mute
XF86AudioRaise
Volume +5%
XF86AudioLower
Volume −5%
XF86AudioPlay
Play / pause
XF86AudioNext
Next track
XF86AudioPrev
Previous track

Brightness (hardware keys)

XF86MonBrightnessUp
Brightness +3%
XF86MonBrightnessDown
Brightness −3%

Launch Applications

Win+D
Run an application
Win+S
Launch WezTerm (terminal emulator)
Win+Shift+S
Launch WezTerm on overlay workspace
Win+F
Launch Neovide (Neovim GUI)
Win+R
Launch Brave browser

Overlay workspaces

F12 / Win+M
Toggle terminal overlay
Win+Shift+M
Move focused window to terminal overlay
Menu / Win+N
Toggle general overlay
Win+Shift+N
Move focused window to general overlay

Window Actions (focused window)

Win+C
Close window
Win+Y
Toggle fullscreen
Win+Space
Toggle floating
Win+O
Toggle horizontal/vertical split

Change Focused Window

Win+H
Focus left
Win+J
Focus down
Win+K
Focus up
Win+L
Focus right

Move Focused Window

Win+Shift+H
Move left
Win+Shift+J
Move down
Win+Shift+K
Move up
Win+Shift+L
Move right

Workspace & Monitor

Win+U/I / Win+Mouse Wheel ↕
Change to prev/next workspace on focused monitor
Win+Shift+U/I
Move focused window to prev/next workspace
Win+Shift+O/P
Move focused window to prev/next monitor

Session

Win+Q
Logout (uwsm stop)
Win+Shift+Q
Force exit Hyprland

Screenshot

Win+;
Screenshot selected region to Pictures and clipboard

Mouse

Win+drag LMB
Move window
Win+drag RMB
Resize window
