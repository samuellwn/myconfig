# Hyprland Keybindings

## Media Controls (hardware keys)

- `XF86AudioMute` — Volume mute
- `XF86AudioRaise` — Volume +5%
- `XF86AudioLower` — Volume -5%
- `XF86MonBrightnessUp` — Brightness +3%
- `XF86MonBrightnessDown` — Brightness -3%
- `XF86AudioPlay` — Play/pause
- `XF86AudioNext` — Next track
- `XF86AudioPrev` — Previous track

## Overlay workspaces

- `F12` / `Win+M` — Open/close terminal overlay
- `Win+Shift+M` — Move window to terminal overlay workspace
- `Menu` / `Win+N` — Toggle general overlay workspace
- `Win+Shift+N` — Move window to general overlay workspace

## Launch Applications

- `Win+D` — Run an application
- `Win+S` — Launch WezTerm (terminal emulator)
- `Win+Shift+S` — Launch WezTerm on overlay workspace
- `Win+F` — Launch Neovide (Neovim GUI)
- `Win+R` — Launch Brave browser

## Window Actions

- `Win+C` — Close focused window
- `Win+Y` — Toggle fullscreen on focused window
- `Win+Space` — Toggle floating on focused window
- `Win+O` — Toggle split direction
- `Win+H` / `Win+J` / `Win+K` / `Win+L` — Move focus left/down/up/right
- `Win+Shift+H` / `Win+Shift+J` / `Win+Shift+K` / `Win+Shift+L` — Move focused window left/down/up/right

## Workspace & Monitor

- `Win+U` / `Win+I` — Switch to prev/next workspace on focused monitor
- `Win+MouseUp` / `Win+MouseDown` — Switch to prev/next workspace on focused monitor
- `Win+Shift+U` / `Win+Shift+I` — Move focused window to prev/next workspace on focused monitor
- `Win+Shift+O` / `Win+Shift+P` — Move focused window to prev/next monitor

## Session

- `Win+Q` — Logout (uwsm stop)
- `Win+Shift+Q` — Force exit Hyprland

## Screenshot

- `Win+;` — Screenshot region → `~/Pictures/screenshot.png` + clipboard

## Mouse

- `Win+drag (left btn)` — Move window
- `Win+drag (right btn)` — Resize window
